ABIA : Agentic Business Intelligence Assistant

Architected an enterprise-grade agentic analytics platform using LangGraph and Groq (Llama-3.3-70B) that eliminates mathematical hallucinations and unsafe dynamic code execution. The LLM acts strictly as a semantic compiler outputting typed Pydantic query plans, delegating 100% of arithmetic and relational joins to a deterministic Pandas engine. Features a cyclic self-healing state graph with automated retry loops, auto-injecting join guardrails, and full observability traced via LangSmith.

LangGraph Groq LPU Llama-3.3-70B Pydantic v2 Pandas Plotly LangSmith Streamlit
Architecture: Semantic plan compilation, deterministic execution safety, cyclic self-healing loops, auto-join injection.
NLP • Transformers IITM Project 86% F1 (Kaggle)
Live App

Multi-Label Emotion Classification via RoBERTa

Fine-tuned a RoBERTa-base transformer with PyTorch & Hugging Face for multi-label emotion classification, securing an 86% macro F1-score on Kaggle. Neutralized severe minority-class sparsity through targeted paraphrasing data augmentation and regex text normalization, paired with calibrated BCEWithLogitsLoss and threshold-based logit filtering. Deployed via a modular Streamlit Cloud app streaming weights dynamically from the Hugging Face Hub.

PyTorch Hugging Face Hub RoBERTa-base BCEWithLogitsLoss Tokenizers NumPy Data Augmentation Regex Streamlit Cloud
Architecture: Minority paraphrasing augmentation, regex text cleaning, threshold logit calibration, decoupled HF Hub weight streaming.
Predictive ML IITM Project R² Improved ~12% (Kaggle)
Kaggle

Predict Purchase Value from User Telemetry

Engineered an end-to-end tabular regression pipeline predicting customer spend from high-dimensional multi-session user telemetry for an IIT Madras Kaggle benchmark. Neutralized severe ≈80% zero-inflation and right-tail skewness via log1p target transformation and inverse exponential inference, boosting validation R² by ~12%. Formulated session-to-user aggregations, target encodings, and PCA dimensionality reduction before benchmarking XGBoost, LightGBM, and Random Forest.

Scikit-learn Random Forest LightGBM XGBoost PCA Pandas NumPy Kaggle
Architecture: Zero-inflated log1p target modeling, multi-session feature aggregation, PCA variance compression.
