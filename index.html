Predictive ML IIT Madras Project R² Improved by ~12%

Purchase Value Prediction from Multi-Session Behavior

GitHub Kaggle Notebook

Built an end-to-end regression ML pipeline to predict customer purchase value from high-dimensional multi-session telemetry. Handled severe zero-inflation (~80% zeros) through logarithmic transformations and user-level aggregation, improving validation R² by ~12%. Conducted exhaustive benchmarks across XGBoost, LightGBM, and Random Forest before selecting Random Forest for final submission.

TECH: Scikit-learn Random Forest XGBoost & LightGBM PCA Pandas NumPy
Methods: Zero-inflated regression, user-level aggregation, PCA dimensionality reduction, feature engineering.
